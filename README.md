<img
  src="assets/project-fake-review.svg"

### Explainable Fake Review Detection Using Hybrid NLP &amp; Stacking Ensemble Learning

**June 2025**

An explainable fake-review detection system built on a balanced dataset of **8,000 reviews**, consisting of **50% fake and 50% genuine reviews**.

The system engineers four feature categories:

`TF-IDF` · `Sentence-BERT Embeddings` · `Sentiment Analysis` · `Handcrafted Linguistic Attributes`

These features feed a **3-model stacking ensemble** consisting of:

`Logistic Regression` · `XGBoost` · `LightGBM`

### Engineering Highlights

- Balanced dataset containing 50% fake and 50% genuine reviews.
- Four feature categories combining semantic, sentiment and linguistic signals.
- Stacking ensemble combining Logistic Regression, XGBoost and LightGBM.
- Interactive Streamlit dashboard providing trust scores, fake-review probability estimates, explainable predictions and visual analytics.

**Technology**

`Python` `Streamlit` `Scikit-learn` `XGBoost` `LightGBM` `Sentence-BERT` `TF-IDF` `Pandas`
